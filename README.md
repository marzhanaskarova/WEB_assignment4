# Assignment 4: Forms and Validation

## About the Project

This project was created for Assignment 4. It contains HTML forms with validation and Bootstrap styling.

## Tasks

- **Task 0:** Create a simple contact form.
- **Task 1:** Add HTML5 form validation.
- **Task 2:** Style the form using Bootstrap.
- **Task 3:** Add Bootstrap validation styles.
- **Task 4:** Create a registration form with different input fields.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Features

- Contact form
- Form validation
- Email validation
- Password confirmation
- Gender selection
- Hobbies checkboxes
- Country dropdown
- Responsive layout
- Submit and reset buttons

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Choose any task from the navigation menu.
